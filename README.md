# MyLittlePet (펫메이트)
idle, incremental, breeding simulation

> 내가 현실에서 성장하는 동안 함께 성장하는 작은 생명체

플레이어가 공부·과제 같은 일을 하는 동안 펫이 함께 성장하고 재화를 생산하는 방치형 펫 육성 게임입니다.
Godot 4.3 이상 (GL Compatibility 렌더러)에서 동작합니다.

## 실행

- Godot 4.3+ 에디터로 `project.godot` 을 열고 실행 (F5)
- 시스템 테스트: `godot --headless -s tests/run_tests.gd -- --no-autoload-save`
- 데모 스크린샷: `godot -s tests/screenshot.gd -- --no-autoload-save <출력.png> [탭 번호]`

세이브 파일은 `user://mylittlepet_save.json` 에 30초마다, 그리고 창을 닫을 때 자동 저장됩니다.

## 화면 크기 / 바탕화면 모드

- 창 크기를 바꾸면 UI 전체가 비율을 유지하며 맞춰집니다 (stretch `canvas_items` / `expand`). 화면보다 큰 창은 시작할 때 작업 영역 안으로 줄어듭니다.
- 상단 바 `－ UI 100% ＋` 로 글자/버튼 크기를 따로 조절할 수 있습니다 (70%~140%, 저장됨).
- 펫집과 탭 사이 경계를 드래그해 비율을 바꿀 수 있습니다. 펫집은 열린 공간 전체가 항상 보이도록 자동으로 맞춰지며, 휠로 확대/축소, 빈 곳 드래그로 이동, 더블클릭으로 원래대로 돌아옵니다.
- **바탕화면에 띄우기 (PiP)**: 테두리 없는 투명 창이 항상 위에 떠서, 펫집과 펫만 바탕화면의 일부처럼 보입니다.
  - 빈 곳을 드래그해 창을 옮기고, 오른쪽 아래 모서리를 드래그해 크기를 바꿉니다.
  - 마우스를 올리면 도구 모음이 나타납니다: 30분 집중 시작/끝내기, 창 크기 −/＋, 투명도(100→80→60→40%), 전체 화면 복귀.
  - 펫을 클릭하면 쓰다듬기. 위치/크기/투명도는 `user://settings.cfg` 에 기억됩니다.
  - 투명 창은 Windows / macOS / 컴포지터가 있는 Linux 에서 지원됩니다.

## 구조

```
scripts/
  data/        밸런스 수치와 정적 데이터베이스
    balance.gd             레벨별 생산량, 경험치 곡선, 집중 보상, 펫집 단계, 숫자 표기
    pet_database.gd        펫 22종 (기본 5 / 합성 10 / 히든 7)
    furniture_database.gd  가구 12종과 가구가 추가하는 행동
    activity_database.gd   펫의 일상 행동 20종
    dialogue_database.gd   애정도에 따라 늘어나는 대사
  core/
    pet_data.gd            펫 상태(레벨/애정도/배고픔/기분/생산량/경험치)와 시간 시뮬레이션
    clock.gd               시간 유틸리티 (로컬 날짜/시간대)
  autoload/    게임 시스템 (싱글톤)
    economy.gd             골드, 누적 생산량, 오프라인 생산분 수령
    activity_log.gd        기억 시스템: 날짜별 집중 기록, 연속 기록, 접속 인사
    focus_manager.gd       집중 세션, 성장 배율, 집중 보상
    house_manager.gd       펫집 확장, 가구 구매/배치/보관
    pet_manager.gd         펫 획득/돌보기/성장/생산, 일상 행동 AI, 오프라인 진행
    collection.gd          도감, 히든 펫 조건
    fusion_manager.gd      합성 레시피와 발견
    save_manager.gd        저장/불러오기, 접속 리포트
    settings.gd            UI 크기, PiP 창 위치/크기/투명도 설정
    event_bus.gd           시스템 ↔ UI 시그널
  ui/          화면 (코드로 구성, 플레이스홀더 아트)
    main.gd                상단 재화 바 + 펫집 + 탭 + 알림 바, UI 크기, PiP 모드 전환
    house_frame.gd         펫집 화면 맞춤 / 확대·축소 / 이동, PiP 창 드래그
    pip_overlay.gd         PiP 정보 표시, 도구 모음, 크기 조절 손잡이
    house_view.gd          펫집 공간 / 가구 / 펫 표시
    pet_node.gd            펫이 가구로 걸어가 행동하는 모습, 말풍선
    furniture_node.gd      가구 그리기, 배치 모드 드래그
    pet_art.gd             성장 단계별 펫 외형 그리기
    pet_popup.gd           펫 관찰 팝업
    tabs/                  집중 / 펫 / 상점 / 펫집 / 합성 / 도감 / 기록 탭
```

## 기획안 대응

| 기획안 | 구현 |
| --- | --- |
| 3-1 펫 성장 | `PetData` 레벨·애정도·배고픔·기분·생산량·경험치. Lv1 1/분 → Lv5 8 → Lv10 30 → Lv20 150 → Lv50 2,000 앵커를 로그 보간 (`Balance.base_production_per_min`) |
| 4 현실 활동 연결 | 집중 세션 30/60/90/120분·자유. 30분: 애정 +3, 경험치 +10%, 생산 +5% / 60분: +7, +25%, +10% … PC 활동은 감시하지 않음 |
| 5 놀고 있으면? | 집중 중 성장 ×1.5, 평소 ×1.0, 48시간 이상 집중 없음 ×0.7. 펫은 죽거나 떠나지 않음 |
| 6 애정도 | 대사 증가, 새 행동(피아노 40, 춤 60, 하트 85) 해금, 생산 보너스 최대 +20%, 합성 조건, 히든 펫 조건 |
| 7 관찰 | 펫 클릭 → 관찰 팝업 (현재 상태/배고픔/애정도/Lv/생산량/지금 하는 일), 바탕화면 PiP 모드(투명·테두리 없음·항상 위) |
| 8 일상 | 밥 먹기, 잠자기, 공놀이, 캣타워, 창문 보기, 다른 펫과 놀기, 돌아다니기, 플레이어 바라보기 등 가중치 기반 자율 행동 |

| 10 획득 | 강아지/고양이/토끼/햄스터/병아리, 펫별 생산량·성장 속도·애정도 상승 별 |
| 11 합성 | 레시피 10종. 공개 조합은 결과 ???, 비공개 조합은 직접 발견. 실패해도 펫 유지 |
| 12 히든 펫 | 도감 x / 22. 레벨, 가구 배치, 접속 시간(새벽), 애정도 100, 누적 집중 10시간, 7일 연속 집중 |
| 13 기억 | 접속 시 "오늘 오래 공부했네!", "요즘 바쁜가 봐...", "우리 같이 7일째야!", "어디 갔다 왔어?" 등. 함께 집중한 시간 10시간 → 공부 안경 외형 |
